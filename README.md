# 🐾 HangingPet

### 치이카와 친구들이 내 맥북 화면 위에서 산다

화면 맨 위에 줄로 매달린 캐릭터들이 대롱대롱 흔들리는 맥용 데스크탑 앱이에요.
마우스를 스치면 흔들리고, 원하는 캐릭터 이미지를 직접 추가해서 쓸 수 있어요.

</div>

---

## ✨ 뭘 할 수 있나요

- 🧵 **줄에 매달려 흔들리기** — 캐릭터마다 줄 두 가닥에 매달려 진자처럼 흔들려요.
- 🖱️ **마우스에 반응** — 스치면 흔들리고, 클릭 통과를 끄면 클릭·드래그로도 흔들 수 있어요.
- 🖼️ **내 이미지 추가** — 설정 창에서 이미지를 추가/삭제해요. 흰 배경은 자동으로 투명 처리돼요.
- ⚙️ **설정 창** — 시작 위치, 캐릭터 간격, 줄 길이, 클릭 통과, 항상 위 고정, 캐릭터별 보이기/숨기기.
- 🖥️ **클릭 방해 없음** — 기본적으로 클릭은 뒤쪽 창으로 통과하고, 마우스를 스칠 때만 반응해요.

## 📦 설치

아직 배포된 DMG는 없어서 직접 빌드해요. (macOS, Node.js 필요)

```bash
git clone https://github.com/naryeo628/Hanging-Chiikawa.git
cd Hanging-Chiikawa
git checkout develop
npm install
npm run dist
```

1. `release/` 폴더의 DMG를 열고 `HangingPet.app`을 `Applications`로 드래그해요.
2. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면, 앱 아이콘을 **우클릭 → 열기**로 실행하면 돼요.
3. 메뉴바의 🐾를 눌러 **로그인 시 자동 실행**을 켜면 부팅할 때 자동으로 떠요.

### Windows

```bash
npm run dist:win
```

`release/`에 설치용 `HangingPet Setup x.x.x.exe`와 설치 없이 실행하는 `HangingPet x.x.x.exe`(portable)가 만들어져요.
서명하지 않은 빌드라 처음 실행할 때 SmartScreen 경고가 뜰 수 있어요 (**추가 정보 → 실행**).
Windows에서는 작업 표시줄 오른쪽 아래 트레이의 발자국 아이콘에서 설정을 열 수 있어요. (Windows에서는 아직 직접 테스트하지 못했어요.)

## 🚀 처음 사용하기

앱에는 캐릭터 이미지가 없어요. 처음에는 캐릭터가 하나도 보이지 않아요.

1. 메뉴바 🐾 (Windows는 트레이 아이콘) → **설정 열기**
2. **캐릭터** 항목에서 **이미지 추가…**로 이미지를 골라요 (여러 장 가능).
3. **배치** 항목에서 시작 위치, 줄 길이, 캐릭터 간격을 조절해요.

## 🛠️ 개발 모드로 실행

```bash
npm install
npm start
```

## 🧩 동작 방식

- `Electron` 기반의 투명 오버레이 창이 화면 상단에 떠서 캐릭터를 그려요.
- 추가한 이미지는 `~/Library/Application Support/hangingpet/characters/`에 저장돼요. 앱에는 이미지가 포함되지 않아요.
- 메뉴바 트레이 아이콘에서 "설정 열기", "항상 위로 고정 / 바탕화면에 붙이기", "로그인 시 자동 실행"을 제어할 수 있어요.

## ⚠️ 저작권 안내

앱에는 캐릭터 이미지가 포함되어 있지 않아요. 본인이 사용할 수 있는 이미지를 설정 창에서 추가해 주세요. 치이카와는 나가노(ナガノ) 작가의 저작물입니다.
