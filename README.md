# 🐾 HangingPet

### 치이카와 친구들이 내 맥북 화면 위에서 산다

화면 맨 위에 줄로 매달린 치이카와 · 하치와레 · 우사기 · 모몽가가 대롱대롱 흔들려요.
마우스를 스치면 흔들리고, 원하는 이미지를 직접 추가할 수 있어요.

</div>

---

## ✨ 뭘 할 수 있나요

- 🧵 **줄에 매달려 흔들리기** — 캐릭터마다 줄 두 가닥에 매달려 진자처럼 흔들려요.
- 🖱️ **마우스에 반응** — 스치면 흔들리고, 클릭 통과를 끄면 클릭·드래그로도 흔들 수 있어요.
- 🖼️ **내 이미지 추가** — 설정 창에서 이미지를 추가/삭제해요. 흰 배경은 자동으로 투명 처리돼요.
- ⚙️ **설정 창** — 시작 위치, 캐릭터 간격, 줄 길이, 클릭 통과, 항상 위 고정, 캐릭터별 보이기/숨기기.
- 🖥️ **클릭 방해 없음** — 기본적으로 클릭은 뒤쪽 창으로 통과해요.

## 📦 설치

1. [Releases](../../releases)에서 DMG 파일을 받거나, 아래 빌드 방법으로 직접 만들어요.
2. DMG를 열고 `HangingPet.app`을 `Applications`로 드래그해요.
3. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면, 앱 아이콘을 **우클릭 → 열기**로 실행하면 돼요.

## 🛠️ 직접 빌드하기

```bash
git clone <this-repo-url>
cd hangingpet
pnpm install

# 실행 (개발 모드)
npm start

# DMG 빌드
npm run dist
```

빌드된 DMG는 `release/` 폴더에 생성돼요.

## 🧩 동작 방식

- `Electron` 기반의 투명 오버레이 창이 화면 상단에 떠서 캐릭터를 그려요.
- 추가한 이미지는 `~/Library/Application Support/hangingpet/characters/`에 저장돼요. 앱에는 이미지가 포함되지 않아요.
- 메뉴바 트레이 아이콘에서 "설정 열기", "항상 위로 고정 / 바탕화면에 붙이기", "로그인 시 자동 실행"을 제어할 수 있어요.

## ⚠️ 저작권 안내

앱에는 캐릭터 이미지가 포함되어 있지 않아요. 본인이 사용할 수 있는 이미지를 설정 창에서 추가해 주세요. 치이카와는 나가노(ナガノ) 작가의 저작물입니다.

## 📝 라이선스

개인/비상업적 용도로 자유롭게 사용해주세요.
